# No. 8

No. 8 is a local desktop visual library for imported images and saved links.

## Stack

- Tauri 2 and Rust
- React 19 and TypeScript
- Vite and Tailwind CSS
- SQLite

## Requirements

- Node.js and npm
- Rust and Cargo
- Tauri system prerequisites for macOS

## Development

Install dependencies:

```sh
npm install
```

Run the Tauri application:

```sh
npm run tauri dev
```

Create a production build:

```sh
npm run tauri build
```

## Local data

No. 8 stores its library in `<Documents>/No. 8 Vault/`. Application metadata and the SQLite database are stored in `<Documents>/No. 8 Vault/.no8/`.
